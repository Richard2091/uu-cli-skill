## 三、性能实测

| 指标 | 数值 |
|---|---|
| 建立 PTY 会话 | 12–18 秒（一次性） |
| 单条命令往返 | 约 1.2 秒 |
| 单次安全写入 | 单段 215 字符（包装后 220） |
| 单条安全输出 | 外层 base64 约 300–500 字符 |
| 推送 | 约 1.3 秒 / 120 字符 b64 |
| 拉取 | 约 1.5 秒 / 120 字符 b64 ≈ 80 B/s |
| 会话残留后设备锁 | >3 分钟（退出码 127） |

**结论**：一次会话跑多条命令，比每条命令新开会话快一个数量级。这是 `--batch` 存在的理由。

## 四、修复历史

记录已解决的问题，供日后回归参考。完整变更见 [CHANGELOG](../CHANGELOG.md)。

### 早期（0.1–0.2）

提示符判定错误（`PS C:` vs `PSC:\`）、`; exit` 抢跑、小步分块写入丢字符、
PSReadLine 污染回显、辅助函数空输出缺陷、跨命令状态丢失、长输出截断、
`New-Object [GzipStream](...)` 语法错误、`--check` 中文乱码、脚本被安全软件查杀。

### 0.3（公开化重构）

1. **CLI 路径硬编码** → 六级自动发现（参数 / 环境变量 / 配置 / 注册表 / PATH / 常见目录）。
2. **设备 ID 硬编码** → 四级解析（参数 / 环境变量 / 配置 / 唯一在线 Windows 设备）。
3. **pywinpty 传字符串 argv 的陷阱**：`PtyProcess.spawn(str)` 会 shlex 切分后按原样查找命令，
   含空格的带引号路径报 `FileNotFoundError`。改为传 **list**。
4. **`term ls/kill` 锁屏也要密码**（新发现），但可经 stdin 传入，不必为短 RPC 开 PTY。
5. **stdout/stderr 拼接导致解析失败**：CLI 把进度写 stderr、JSON 写 stdout，拼接后 `Extra data`。
   改为先解析 stdout，用 `raw_decode` 跳过前导杂音。
6. **`success:false` 被当成空结果**：现在统一转成错误。
7. **本地 PTY 退出 ≠ 远端会话结束**：会残留 `running` 占槽。现在收尾时显式 kill，
   并等本地 PTY 真正退出后再 kill（避免 `already attached`）。
8. **服务限流**：快速连续 `term` 连接触发 code 105。加了退避重试 + kill 间隔，
   并把限流与"密码错误"在错误信息里区分。
9. **登录失败原因误报**：现在记录真实原因（无密码 / 限流 / 被远控 / 版本过低 / 会话被占）。
10. **`--desktop` 两个探测项报"找不到类型"**：需先 `Add-Type -AssemblyName System.Windows.Forms`。
11. **命令失败被判成成功（严重）**：原实现用 `$?`，而 `$o = (&$cmd) 2>&1` 之后 `$?` 已被覆盖，
    所以任何失败命令都显示 `EXIT_CODE=0`，`--stop-on-error` 完全失效。
    改为检测 `ErrorRecord` 并编码进标记（`@guid@0|1@base64#`），同时保留对 `-EA 0` 的容错。
12. **两条辅助函数定义连续写入导致半定义**：症状是之后每条命令都 "no marker"。
    改为每个定义单独写入 + 等提示符 + 独立重试，往返失败时**重写定义**。
13. **`split_command` 无脑按 `;` 切**：会切断引号内的分号和 `if/else`。改为引号/括号感知。
14. **`--kill-all` 会误杀别人的会话**：原前缀 `uu/q/p/c` 会匹配 `core`、`prod`、`python`。
    改为锚定正则，旧前缀需 `--kill-legacy`。
15. **密码明文落盘**：`os.chmod(0o600)` 在 Windows 上对 DACL 无效。改为 DPAPI 加密 + `icacls`，
    配置移到 `%APPDATA%\uu-cli\`，旧文件迁移后删除。
16. **`--json` 契约失效**：8 个动作里 5 个输出不是 JSON。改为所有动作输出单个 JSON 对象。
17. **`--sessions`/`--kill` 抛裸 traceback**：改为全局兜底，统一 `ERROR=` 输出。
18. **`--chunk 0` 除零**：加范围校验（16–200）。
19. **本地路径错误抛 traceback**：`--batch` 文件不存在、`--pull` 目标目录不存在都改为干净报错。
20. **`uu-doctor.ps1` 在 PowerShell 5.1 上必坏**：原生 stderr 被包装成 ErrorRecord，
    `2>&1 | Out-String` 后再解析 JSON 必然失败。改为分流捕获 + 显式 UTF-8。
21. **远端临时文件放在 `C:\Users\Public`**（本机其他用户可读）：改到 `%TEMP%\uu-*` 并 `finally` 清理。
22. **`--keep` / `--attach` 是伪需求**：实测会话不能被跨进程复用，已删除这两个参数。

## 五、已知限制

1. **截屏内容验证需要远端解锁**：目前只验证了采集/编码链路，画面内容是锁屏。
2. **剪贴板**：锁屏读 100% 失败；锁屏写入调用不报错但无法验证；解锁后需复测。
3. **浏览器 CDP**：CLI 无端口映射命令，需人工配置一次；推荐改为"远端本地跑 Playwright"
   （该方案需要远端额外装 Python）。
4. **拉取 >64KB 不可行**：单行响应约 50% 损坏率，重试成本高。
5. **不驱动本机 UU 客户端 GUI**：策略边界——只操作远端。
6. **跨调用复用会话不可行**：一个会话同时只能被一个客户端持有，持有者消失后 `running` 行陈旧。
7. **UIA 对 Qt / 自绘界面无效**：`Invoke()` 常无反应，只能真实鼠标。
